Key distinction — WUS vs LP-WUS:
Rel-16/17 WUS still requires the main radio to decode PDCCH to check for WUS — it saves on-duration only when no data is scheduled, but MR must wake for detection. Rel-19 LP-WUS introduces a separate low-power receiver (LP-WUR) that operates independently — MR stays fully off. Up to 90% power saving vs standard iDRX (3GPP Rel-19 LP-WUS specification).
Standard DRX limit — crystal drift, not channel:
The 320ms–2.56s iDRX cycle is set by TCXO crystal drift (±0.1–0.5 ppm), not by channel coherence. The UE must wake frequently enough to remain within the CP window despite oscillator drift. Doppler is a non-factor in terrestrial (BS and UE are both stationary). This assumption breaks completely in NTN.

Section 3 · Proposed Method
CW pilot tone as continuous coarse sync reference
The M2 CW pilot tone (already transmitted for Doppler pre-calibration, 0.004% OH) doubles as a continuous LP-WUR beacon — at zero additional waveform cost. A low-power narrow-FFT receiver monitors whether the CW tone is at its ephemeris-predicted frequency. Deviation = wake-up trigger. No deviation = sleep on.

How CW-aided DRX works
① Sleep — LP-WUR monitors CW
Low-power receiver (~µW) monitors CW energy in a 10Hz FFT bin. Expected CW frequency = f₀ + Δf_doppler(t) — pre-computed from ephemeris. Main radio completely off.
② Coarse sync maintained automatically
Crystal drift appears as slow CW frequency deviation → LP-WUR detects it. Doppler shift is pre-computed, so it is expected and not a false alarm. Atmospheric scintillation: amplitude variation only → does not affect frequency sync.
③ Wake-up triggers
CW frequency deviates unexpectedly (ephemeris stale or anomaly) → wake MR.
Paging timer fires (network has data) → wake MR.
Handover geometry trigger (elevation crossover) → wake MR.
④ Fine sync at wake-up (1–2 slots)
MR wakes with CW already providing coarse frequency reference. SSB/ZC in symbol 0 provides fine sync. PDCCH monitored. No blind search — CW pre-verified geometry.
Patent note: Using an existing CW pilot tone (transmitted for Doppler pre-calibration) as a continuous low-power coarse sync reference enabling extended NTN DRX sleep cycles — with ephemeris-predicted expected frequency as the detection threshold — is a potentially novel combination not found in published 3GPP WUS/LP-WUS literature or known patent filings (search conducted Aug 2026). Literature grounding:
Zhang et al. (IEEE WCL 2021): LSTM-based LEO channel predictor using temporal correlation — trains offline, infers online. Achieves near-genie channel estimation at short horizons.
DRIFT (De Filippo et al., Bologna 2025): pilots only in first slot, CNN/LSTM predicts subsequent slots. 12% spectral efficiency gain vs conventional pilot-based systems.
Physics-Informed DT (2025): uses real Starlink ephemeris + ERA5 weather — physics-guided diffusion outperforms pure data-driven baselines.
Why geometry features matter in NTN (not terrestrial):
Terrestrial LSTM: only past channel samples as input — no geometry available (BS is fixed).
NTN with ephemeris: elevation angle and elevation rate are known exactly at any future time. These features capture: (1) path loss trend, (2) Doppler rate, (3) atmospheric path length change. Geometry features reduce prediction MSE by ~4–8 dB at T=30s vs samples-only baseline (our simulation result below, consistent with physics-informed DT findings).
